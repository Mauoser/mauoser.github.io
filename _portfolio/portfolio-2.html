Roomalize is an AI-powered architectural visualization SaaS that transforms 2D floor plans into photorealistic 3D renders. The React and Vite frontend uses Tailwind CSS for the interface, Puter.js for serverless KV storage and cloud hosting, and Gemini AI to drive photorealistic rendering from uploaded floor plans.
